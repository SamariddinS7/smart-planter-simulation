# 演示操作说明

## 演示前准备

1. 确认电脑和手机连接同一 Wi-Fi。
2. 执行 `./scripts/start-local.sh`，使用终端输出的手机访问地址。
3. 打开右上角演示控制面板，点击“一键重置”，确保设备回到两台在线、一台离线的初始状态。
4. 未配置 DeepSeek 时使用“仿真问答”；配置后可切换“真实 AI”。

## 推荐演示流程

1. **养护问答**：选择 A01，点击“今天需要浇水吗？”，展开“建议依据”，说明回答引用的是带时间的仿真设备快照与公开资料。
2. **趋势预测**：点击“查看需水趋势”，调整温度和光照，运行预测；展开模型与基线对比，说明这是可解释的参数化情景模型，不是已训练的农业 AI 模型。
3. **设备协同**：进入设备页，选择 A01、B02，创建养护检查或模拟浇水；确认目标设备、任务类型与模拟供水量。
4. **回执验证**：查看任务从待执行、执行中到成功的变化，以及每台设备的进度、回执和模拟供水量。
5. **异常演示**：创建任务后，在控制面板将目标设备设为离线；任务应失败并保留已经发生的模拟供水记录。
6. **恢复演示**：恢复设备在线，或一键重置，重新开始下一轮展示。

## 讲解边界

- 页面中的湿度是“湿度相对值”，不是经过土壤标定的体积含水率。
- 趋势范围是模拟情景边界，不是统计置信区间。
- 模拟浇水对应独立灌溉模块，不代表 PlantsIO 原生支持水泵控制。
- 未配置 DeepSeek 或未完成真实模型调用时，应明确称为“仿真问答”。
- 无真实数据训练和海外试点，不展示节水率、准确率等未经验证的指标。

## 常见问题

- 手机打不开：确认同一网络、电脑未休眠，使用当前 Network 地址；必要时允许防火墙访问 Node.js。
- 预测失败：设备可能离线，或演示面板已注入“历史数据不足”。恢复在线或一键重置。
- AI 失败：切换仿真问答；检查 `.env` 中密钥、模型名称和电脑网络。
- 任务不执行：检查仿真是否暂停；恢复后任务继续。
