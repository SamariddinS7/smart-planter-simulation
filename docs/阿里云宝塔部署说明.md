# 阿里云服务器与宝塔部署说明

本轮未实际部署。本说明用于后续部署，正式公网使用前必须增加登录或访问控制。

## 环境

- Node.js 20+、MongoDB、Nginx。
- 使用宝塔 Node 项目管理器或 PM2 运行 Express。
- 项目目录示例：`/www/wwwroot/smart-planter`。
- 数据库保持独立名称 `smart_planter_demo`。

## 构建与启动

```bash
cd /www/wwwroot/smart-planter
npm ci --omit=dev=false
npm test
npm run build
cp .env.example .env
# 在宝塔环境变量中配置生产值，不要把密钥写入仓库
npm start
```

`.env` 至少配置：

```dotenv
HOST=127.0.0.1
PORT=3001
MONGO_URI=mongodb://127.0.0.1:27017
MONGO_DB=smart_planter_demo
DEEPSEEK_API_KEY=
DEEPSEEK_MODEL=
DEEPSEEK_BASE_URL=https://api.deepseek.com
AI_TIMEOUT_MS=20000
```

## Nginx 反向代理

将域名反向代理到 `http://127.0.0.1:3001`，并启用 HTTPS。示例核心配置：

```nginx
location / {
    proxy_pass http://127.0.0.1:3001;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

## 公网前必须完成

- 增加登录或限制来源 IP；当前免登录版本仅为可信局域网演示。
- 在云安全组只开放 80/443，不开放 MongoDB 和 3001。
- 配置 HTTPS、进程自启动和日志轮转。
- DeepSeek 密钥使用宝塔环境变量管理，禁止写入网页或仓库。
- 定期执行 `mongodump`，并在隔离环境验证 `mongorestore`。

## 备份与恢复

```bash
./scripts/backup.sh
./scripts/restore.sh backups/时间戳/smart_planter_demo
```

恢复脚本要求输入 `RESTORE_DEMO`，并且只允许目标数据库为 `smart_planter_demo`。
